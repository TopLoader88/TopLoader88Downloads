Install on a phone or Mac

iPhone/iPad: open in Safari, tap Share, then Add to Home Screen. Android: use Chrome's Install app or Add to Home Screen. Mac: use Safari's File > Add to Dock, or Chrome/Edge's Install app.

Open the installed app and save its offline files there if asked. Keep this app visible while reading; phones pause microphone capture when locked or backgrounded. A current Safari/iOS 17+ or Chrome is recommended.

Browser storage can be removed by the browser or device. If saved files disappear, reconnect and save them again. The Android APK includes them without this download step.

TXT, MD, Word DOCX, PDF, RTF, SRT and VTT. Paste from Word or Pages to keep supported fonts and emphasis. Up to 200,000 characters.

Scripts and formatting are saved in this browser. Editing stops the microphone. Original colors and page layout are not copied, to keep the script readable.
